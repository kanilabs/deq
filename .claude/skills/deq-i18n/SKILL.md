# Deq i18n

- Locales: `en` (default, no URL prefix), `ckb` (Sorani, Arabic script, right-to-left, `/ckb/`), `kmr` (Kurmanji, Latin script, `/kmr/`). Locale data (`lang`, `dir`, label, review flag) is `LOCALE_INFO` in `apps/site/src/i18n/index.ts`.
- No hard-coded UI strings. Site strings live in `apps/site/src/i18n/messages/`: add the key to `en.ts` first (it defines `Messages` and `MessageKey`), then to `ckb.ts` and `kmr.ts`, which end with `as const satisfies Messages`, so a missing or extra key fails `astro check`. `test/i18n.test.ts` also checks non-empty values and that every `{placeholder}` of the English text is kept.
- Look strings up with `useTranslations(locale)` and `format`; numbers with `formatNumber` (Sorani uses Arabic-Indic digits). Links with `localizedPath(locale, page)`.
- Starlight's own UI strings for ckb and kmr are in `src/i18n/starlight.ts`; docs pages per locale in the repo `docs/{ckb,kmr}/` (ADR 0020): every `docs/guide/*.md` needs a ckb and kmr file with the same name and `sidebar.order`, opening with the draft notice that links the issue tracker; copy UI labels exactly from `src/i18n/messages/`, and link the localized site (`https://kanilabs.github.io/deq/<locale>/...`).
- Use CSS logical properties (`inline-size`, `margin-inline-start`, `inset-inline-end`) so layouts mirror in RTL. Sorani text uses Vazirmatn first (`tokens.css`).
- AI-drafted translations are marked "needs native review" until a native speaker approves them: the banner on every ckb/kmr page, `needsReview` in `LOCALE_INFO`, and the `needs-native-review` status of shape names in `spec/`. Only a native reviewer changes a name to `verified`.
- Put Kurdish text that appears inside English pages (or the reverse) in an element with its own `lang` (and `dir="rtl"` for Sorani).
- Studio strings are the `studio.*` keys (plus `category.*`); `studioMessages(catalog)` passes only those to the island, and components translate with `translator(messages)`. Each shortcut action needs a `studio.action.<action>` key. Inspector arrange buttons reuse those labels; history labels are `studio.act.*`. The shape editor (8c) uses `studio.mine*`, `studio.shape.*` (errors in `studio.shape.error.*`), `studio.part.<primitive>`, `studio.tool.*`, `studio.bool.*` and `studio.paint.*`; spec field names (`cx`, `r`, `d`) stay untranslated code. The 8c ckb and kmr strings are drafts awaiting native review. Phase 8d adds `studio.file`, `studio.open|save|share|export`, `studio.io.*` (notices, errors in `studio.io.error.*`) and `studio.export.*`; the ckb and kmr texts for 8d are drafts awaiting native review. Phase 9d adds `nav.leet`, `nav.generate`, `leet.*`, `generate.*` and `fonts.leet*` for the pages, and `studio.tab.leet|generate`, `studio.act.insertScene`, `studio.leet.*`, `studio.gen.*` and `studio.scene.*` for the shared panels (pages and Studio tabs use the same keys); the 9d ckb and kmr texts are drafts awaiting native review. Leet input stays plain text, and the PUA font text is always `dir="ltr"` (Sorani lines are already in visual order). Phase 10a adds `nav.story`, `nav.sources`, `home.card.story`, `story.*` and `sources.*`. The ckb and kmr chapters in `content/story/` and the captions and alt text in `content/story/images.json` are drafts awaiting native review. Keep names of people and places as the sources spell them, and keep source titles in their original language. Phase 10b adds `nav.showcase`, `home.card.showcase` and `showcase.*`. The ckb and kmr descriptions in `content/showcase.json` are drafts awaiting native review. Project names stay as their owners write them (`lang="en"` on the card title).
