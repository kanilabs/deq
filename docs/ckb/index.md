> ئەم دەقە ڕەشنووسە و هێشتا پێویستی بە پێداچوونەوەی ئاخێوەرانی سۆرانی هەیە. ڕاستکردنەوەکان لە [لیستی کێشەکان](https://github.com/kanilabs/deq/issues) بەخێربێن.

دەق نەخشەکانی دەقی کوردیی کۆن لەسەر یەک تۆڕی ٢٤ یەکەیی دەکێشێت، وەک ئایکۆن، فۆنت و کۆد. ئەم پەڕانە ڕوون دەکەنەوە چۆن هەموو بەشێکی بەکاربهێنیت. هەمان ئەو فایلانەن کە لە GitHub، لە بوخچەی `docs/` دەتوانیت بیانخوێنیتەوە.

## ڕێنماییەکان

- [دەستپێکردن](guide/getting-started.md): دەق چی تێدایە، و خێراترین ڕێگا بۆ بەکارهێنانی شێوەیەک.
- [ستۆدیۆ](guide/studio.md): هەموو پانێڵێکی تابلۆی دیزاین.
- [هەناردن](guide/exporting.md): هەر ٢٣ فۆرمات و کەی هەر یەکەیان بەکاربهێنیت.
- [شێوەی تایبەت](guide/custom-shapes.md): دەستکاریکەری شێوە، دەستکاریکەری ڕێڕەو و شێوەکانم.
- [لیتی دەق](guide/leet.md): دەق کە بە نەخشەکانی دەق نووسراوە.
- [دروستکەری نەخش](guide/generate.md): پشتێن، تۆڕ، گوڵ و لێوار بە تۆو.
- [ئاڵا](guide/flag.md): ئاڵای کوردستان، ڕەنگ و جۆرەکانی.
- [فۆنتەکان](guide/fonts.md): فۆنتەکانی ئایکۆن و لیت لەسەر Linux، macOS و Windows.
- [دامەزراندن و بەکارهێنانی بێ ئینتەرنێت](guide/pwa.md): دەق بێ ئینتەرنێت بەکاربهێنە.

## بۆ گەشەپێدەران (بە ئینگلیزی)

- [پاکێجەکان](../dev/packages.md): پاکێجەکانی JavaScript، Python و Rust.
- [هێڵی فەرمان](../dev/cli.md): ئامرازی `deq` بە Node.js، Python و Rust.
- [ئامادەکردنی گەشەپێدان](../dev/setup.md): دروستکردن و تاقیکردنەوەی پرۆژەکە.
