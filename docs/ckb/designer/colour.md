> ئەم دەقە ڕەشنووسە و هێشتا پێویستی بە پێداچوونەوەی ئاخێوەرانی سۆرانی هەیە. ڕاستکردنەوەکان لە [لیستی کێشەکان](https://github.com/kanilabs/deq/issues) بەخێربێن.

شێوەکانی دەق ڕەنگی خۆیان نییە. بە `currentColor` دەکێشرێن، بۆیە ڕەنگی دەقی دەوروبەریان وەردەگرن، و تۆ لەو شوێنەی بەکاریان دەهێنیت ڕەنگەکە هەڵدەبژێریت.

## هەڵبژاردنەکانی ڕەنگ

| هەڵبژاردن       | بنەڕەت         | چی دەکات                                                      |
| --------------- | -------------- | ------------------------------------------------------------- |
| `color`         | `currentColor` | ڕەنگی هێڵ و خاڵەکان (هەر ڕەنگێکی CSS)                         |
| `layerColors`   | هیچ            | ڕەنگێک بۆ هەر چینێک، بۆ نموونە `{ "rays": "#FEBD11" }`        |
| `fill`          | `none`         | پڕکردنەوە بۆ دەورە داخراوەکان (بازنە، فرەگۆشە، ڕێڕەوی داخراو) |
| `fillOpacity`   | 1              | ڕوونیی پڕکردنەوە                                              |
| `strokeOpacity` | 1              | ڕوونیی هێڵ و خاڵەکان                                          |
| `background`    | `none`         | ڕەنگێک لە پشت هەموو شێوەکە                                    |

هەمان هەڵبژاردنەکان لە پشکنەری ستۆدیۆدان (**ڕەنگ**، **ڕەنگی چینەکان**، **پڕکردنەوە**، **باکگراوند**)، لە [هێڵی فەرمان](../../api/commands.md) و لە هەموو پاکێجێکدا. ناوی چینەکان لە هەر پەڕەیەکی ئایکۆندا ڕیز کراون. لە ئامرازەکانی دیزایندا، گرووپەکانی Layered SVG ڕەنگ بکە؛ [ڕێنماییەکانی ئامرازەکان](../tools/inkscape.md) پیشانی دەدەن چۆن.

## ڕەنگەکانی ئاڵا

ئاڵای کوردستان چوار ڕەنگ بەکاردەهێنێت، لە [`spec/flag.json`](../../../spec/flag.json):

| ڕەنگ | Hex       |
| ---- | --------- |
| سوور | `#ED2024` |
| سپی  | `#FFFFFF` |
| سەوز | `#278E43` |
| زەرد | `#FEBD11` |

ڕەنگدانێکی سروشتین بۆ دیزاینەکانی دەق، بەڵام هیچ جووتێکیان بۆ دەقی بچووک بەس بەهێز نییە. ڕێژەی جیاوازییان (WCAG 2)، کە پشکنەر دەیپشکنێت:

| جووت            | ڕێژە | بەکارهێنان                                              |
| --------------- | ---- | ------------------------------------------------------- |
| سوور لەسەر سپی  | 4.35 | تەنها گرافیک و دەقی گەورە (3:1 پێویستە)؛ نەک دەقی بچووک |
| سپی لەسەر سەوز  | 4.17 | تەنها گرافیک و دەقی گەورە                               |
| سوور لەسەر زەرد | 2.59 | تەنها ڕازاندنەوە                                        |
| سەوز لەسەر زەرد | 2.48 | تەنها ڕازاندنەوە                                        |
| زەرد لەسەر سپی  | 1.68 | هەرگیز بۆ گەیاندنی واتا                                 |
| سوور لەسەر سەوز | 1.04 | هەرگیز بۆ گەیاندنی واتا                                 |

کاتێک شێوەیەک واتایەک دەگەیەنێت (دوگمە، دۆخ، بەستەر)، لانیکەم **3:1** جیاوازیی لەگەڵ باکگراوندەکەی هەبێت، کەمترین ئاستی WCAG بۆ گرافیک. مەرەکەبی ڕەش یان سپی لەسەر ڕەنگێکی ئاڵا زۆرجار هەڵبژاردنی سەلامەتە. هەرگیز ڕەنگی خودی ئاڵاکە مەگۆڕە، ڕایمەکێشە و تیشکەکانی مەگۆڕە؛ بڕوانە [ڕێنماییی ئاڵا](../guide/flag.md).

## ڕووناک و تاریک

`currentColor` شوێن ڕەنگی دەق دەکەوێت، بۆیە شێوەیەک لە ناو دەقدا خۆی لەگەڵ ڕووکاری ڕووناک یان تاریک دەگۆڕێت. ڕەنگە جێگیرەکان وا ناکەن: لەسەر هەردوو باکگراوند بیانپشکنە، یان ڕەنگی تایبەت بە ڕووکاری تاریک بدە.

## ئایکۆنی دەستڕاگەیشتوو

- شێوەیەک کە واتای هەیە ناوی پێویستە. ڕێندەرەکان `<title>`، `role="img"` و `aria-label` بە SVG ـەکە دەدەن، هەموویان بە بنەڕەت ناوی ئینگلیزیی شێوەکەن. `title` یان `ariaLabel` دابنێ بۆ وەسفکردنی ئەوەی ئایکۆنەکە دەیکات، بۆ نموونە "داگرتن".
- شێوەیەکی ڕازاندنەوە لە تەنیشت دەقێکدا کە هەمان شت دەڵێت، دەبێت لە خوێنەرەکانی شاشە بشاردرێتەوە: `title: ""` بدە، و SVG ـەکە لە جیاتی ئەوە `aria-hidden="true"` وەردەگرێت.
- تەنها ڕەنگ بەکارمەهێنە بۆ جیاکردنەوەی شێوەکان؛ شێوەکەش بگۆڕە.
- لە قەبارەی بچووکدا ٢٤ پیکسڵ و هێڵی بنەڕەتی بهێڵەرەوە. هێڵی باریکتر لە 1.5 پیکسڵ بە زەحمەت دەبینرێت.
