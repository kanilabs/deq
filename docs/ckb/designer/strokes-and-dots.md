> ئەم دەقە ڕەشنووسە و هێشتا پێویستی بە پێداچوونەوەی ئاخێوەرانی سۆرانی هەیە. ڕاستکردنەوەکان لە [لیستی کێشەکان](https://github.com/kanilabs/deq/issues) بەخێربێن.

شێوەکانی دەق کێشانی هێڵین، وەک ئەو دەقانەی لێیانەوە هاتوون. چەند ڕێسایەکی کەم هەموو هێڵ و خاڵێک وەک یەک ڕادەگرن، بۆیە شێوەکان دەتوانن لە تەنیشت یەک دابنرێن، تێکەڵ بکرێن و بەشەکانیان هاوبەش بێت.

## هێڵەکان

- **ئەستووری ٢ یەکە.** بە ٢٤ پیکسڵ دەکاتە ٢ پیکسڵ؛ بە ٤٨ پیکسڵ، ٤ پیکسڵ. هێڵەکە لەگەڵ شێوەکە گەورە دەبێت، مەگەر ئەستوورییەکی جێگیر داوا بکەیت (بڕوانە خوارەوە).
- **سەری خڕ و جومگەی خڕ.** بۆیە هێڵێک ١ یەکە لە خاڵەکانی کۆتایی تێدەپەڕێت، و گۆشەکان خڕن.
- **بێ پڕکردنەوە، مەرەکەبی `currentColor`.** هێڵێک ڕەنگی دەقی دەوروبەری وەردەگرێت، مەگەر ڕەنگێکی بۆ دابنێیت.
- **٣ یەکە لە نێوان هێڵە ناوەڕاستە تەریبەکاندا.** بە هێڵی ٢ یەکەیی، ١ یەکە بۆشایی لە نێوان هێڵەکاندا دەمێنێتەوە. بۆ هێڵە لارەکان، بە ستوونی لەسەر هێڵەکە بپێوە، نەک بە درێژایی تەوەرێک.

### گۆڕینی هێڵ

هەموو ڕێندەرەکان، ستۆدیۆ و پێکهاتەکانی ئایکۆن هەمان هەڵبژاردنەکان وەردەگرن:

| هەڵبژاردن             | بنەڕەت  | چی دەکات                                                 |
| --------------------- | ------- | -------------------------------------------------------- |
| `strokeWidth`         | 2       | ئەستووریی هێڵ بە یەکەی تۆڕ                               |
| `absoluteStrokeWidth` | false   | هێڵەکە لە هەموو قەبارەیەکدا `strokeWidth` پیکسڵ ڕادەگرێت |
| `linecap`             | `round` | `round`، `butt` یان `square`                             |
| `linejoin`            | `round` | `round`، `miter` یان `bevel`                             |
| `strokeOpacity`       | 1       | ڕوونیی هێڵ و خاڵەکان                                     |

هێڵی باریکتر (1.5 یان 1) بۆ قەبارەی گەورە و پێکهێنانی چڕ گونجاوە. لە ٢٤ پیکسڵ و خوارتر 2 بهێڵەرەوە، چونکە هێڵی باریکتر لێڵ دەبێت. بە `absoluteStrokeWidth`، ئایکۆنێکی ٤٨ پیکسڵی هێڵی ٢ پیکسڵی دەمێنێت لە جیاتی ئەوەی ببێتە ٤ پیکسڵ، کە لە تەنیشت دەقدا بەسوودە. لیستی تەواو لە [سەرچاوەی API ـی core](../../api/core.md)دایە.

## خاڵەکان

- **خاڵەکان بازنەی پڕکراون**، نەک هێڵ. لە ناو شێوەکاندا **نیوەتیرەیان ١**ە، بۆیە خاڵێک هێندەی هێڵێک پانە.
- **خاڵی گەورە** نیوەتیرەی ٢ ـە. شێوەی سەربەخۆی [`dot`](https://kanilabs.github.io/deq/ckb/icons/dot/) بەکاری دەهێنێت تا لە قەبارەی بچووکیشدا بخوێندرێتەوە.
- `dotScale` نیوەتیرەی هەموو خاڵەکان چەند هێندە دەکات، بۆ نموونە 1.5 بۆ خاڵی قورستر لە قەبارەی گەورەدا.

## پێکهاتەکان

هەموو شێوەیەک لە هەمان بەشەکان دروست دەکرێت، کە لە ژێر `modules` لە [`spec/grid.json`](../../../spec/grid.json) ڕیزکراون. پشکنەر هەر نیوەتیرەیەکی تری بازنە یان خاڵ ڕەت دەکاتەوە.

| پێکهاتە      | قەبارە                                     | نموونە                                                                          |
| ------------ | ------------------------------------------ | ------------------------------------------------------------------------------- |
| بازنەی خۆر   | r 5                                        | [بازنەی خۆر](https://kanilabs.github.io/deq/ckb/icons/roj-sun-circle/)          |
| ئەڵقە        | r 3                                        | [خۆر بە تیشکەوە](https://kanilabs.github.io/deq/ckb/icons/sun-rays/)            |
| مووروو       | r 2 (هێڵکراو)                              | [زنجیر](https://kanilabs.github.io/deq/ckb/icons/chain/)                        |
| خاڵەکان      | r 1 (بچووک)، r 2 (گەورە)                   | [گوڵی خاڵ](https://kanilabs.github.io/deq/ckb/icons/dot-rosette/)               |
| تیشکەکان     | 2.5 لە دوای بازنەکە دەست پێدەکەن، 2.5 درێژ | [نیوە خۆر](https://kanilabs.github.io/deq/ckb/icons/roj-half-sun/): r 7.5 تا 10 |
| V            | دوو هێڵ بە 45°، 3 × 3 یان 6 × 6            | –                                                                               |
| هەنگاوی 45°  | هێڵی تەریبی 45° بە دووریی 4.5              | [کەڵەکەی شێوەی V](https://kanilabs.github.io/deq/ckb/icons/chevron-stack/)      |
| ددان، نیشانە | 3 درێژ، هەر 3 یەکە جارێک                   | [شانە](https://kanilabs.github.io/deq/ckb/icons/comb/)                          |

بۆچی 4.5 بۆ هەنگاوی 45°: دوو هێڵی 45° کە بە درێژایی تەوەرێک 4.5 لە یەک دوورن، بە ستوونی لەسەر هێڵەکان 4.5 × sin 45° ≈ 3.18 لە یەک دوورن، کەمێک زیاتر لە کەمترین ٣ یەکە.

V هەمیشە دوو هێڵی جیایە لە یەک لوتکەی هاوبەشەوە، هەرگیز یەک پۆلیلاین نییە، بۆیە هەر باڵێک بە جیا پیشان دەدرێت، دەشاردرێتەوە یان ڕەنگی دەگۆڕدرێت.

## چینەکان

هەر بەشێکی شێوەیەک چینی خۆیەتی (`sun`، `rays`، `dot`، ...)، و هەناردنە چیندارەکان بە جیا دەیانهێڵنەوە: چینی Inkscape لە Layered SVG، چینی PDF لە PDF و AI، چینی پیکسڵ لە PSD. پەڕەی ئایکۆن چینەکانی شێوەیەک ڕیز دەکات، و `layerColors` ڕەنگێکی جیا بە هەر چینێک دەدات. بڕوانە [هەناردن](../guide/exporting.md).
