> ئەم دەقە ڕەشنووسە و هێشتا پێویستی بە پێداچوونەوەی ئاخێوەرانی سۆرانی هەیە. ڕاستکردنەوەکان لە [لیستی کێشەکان](https://github.com/kanilabs/deq/issues) بەخێربێن.

هەموو پەڕەیەکی ئایکۆن لە ماڵپەڕەکەدا بەشێکی **دروستکردن**ی هەیە، کە لە فایلی شێوەکە لە [`spec/shapes/`](../../../spec/shapes/) دروست کراوە. هەموو ئەوەی پێویستتە پیشانی دەدات بۆ ئەوەی شێوەکە لە هەر ئامرازێک و بە هەر قەبارەیەک دووبارە بکێشیتەوە، بە هەمان ئەو ژمارانەی ڕێندەرەکان بەکاریان دەهێنن.

## بەشەکە چی پیشان دەدات

- **کێشانەکە.** تۆڕی ٢٤ یەکەیی لەگەڵ هێڵە ناوەڕاستەکانی، هێڵە سەرەکییەکان (بازنە، چوارگۆشە، لاکێشەی ستوونی و ئاسۆیی) و ناوچەی زیندوو بە هێڵی پچڕپچڕ، و شێوەکە لە سەرووی هەموویانەوە. خاڵەکان ناوەڕاستی بازنە، کەوانە، ئەستێرە و دووبارەکراوەکان دیاری دەکەن.
- **هەنگاوەکان.** هەنگاوەکانی دروستکردن بە زمانێکی سادە، لەگەڵ بیرکاریی پشت هەر ژمارەیەک: نیوەتیرە، گۆشە، یەکبڕین و بۆچی هەر بەهایەک هەڵبژێردراوە. (ئێستا بە ئینگلیزین.)
- **بنەماکان.** یەک ڕیز بۆ هەر بەشێکی سەرەکی: ناسنامە، چین، جۆری بنەما و بەهاکانی. تێبینییەک دەڵێت کەی بەشێک تەنها بۆ هەندێک بەهای پارامیتەر دەکێشرێت.
- **پێوانەکان.** ئەو ژمارانەی لە شێوەکە بە پارامیتەرە بنەڕەتییەکانی هەژمار کراون.

## بەهای بنەماکان

بەهاکان وەک لە پێوەرەکەدا نووسراون، بە یەکەی تۆڕ، و گۆشەکان بە پلە.

| جۆر          | بەهاکان                                                                                      |
| ------------ | -------------------------------------------------------------------------------------------- |
| `line`       | `x1 y1 x2 y2`: هەردوو خاڵی کۆتایی                                                            |
| `circle`     | `cx cy r`: ناوەڕاست و نیوەتیرە                                                               |
| `dot`        | `cx cy r`: بازنەیەکی پڕکراو، نیوەتیرە ١ ئەگەر نەدرابێت                                       |
| `arc`        | `cx cy r start end`: پلە بە ئاراستەی کاتژمێر لە تەوەری x ـی ئەرێنی (کاتژمێر ٣)               |
| `polyline`   | `points`: هێڵێکی کراوە بە ناو خاڵەکاندا                                                      |
| `polygon`    | `points`: دەورێکی داخراو                                                                     |
| `path`       | `d`: داتای ڕێڕەوی SVG، تەنها `M L H V C Q Z` ـی ڕەها؛ ژمارەکانی دوای `C` و `Q` خاڵی کۆنترۆڵن |
| `rect`       | `x y width height`                                                                           |
| `ellipse`    | `cx cy rx ry`                                                                                |
| `star`       | `cx cy points outerRadius innerRadius rotation`                                              |
| `repeat`     | `count` کۆپی لە توخمەکە، هەر یەکە بە `step` دەجوڵێت، یان بە درێژایی `spread` بڵاو دەبێتەوە   |
| `radial`     | `count` کۆپی بە دەوری `center`، لە `start` بە درێژایی `sweep` پلە                            |
| `concentric` | `count` کۆپی بە دەوری `center`، کۆپیی i بە 1 − i × `scaleStep` بچووک دەکرێتەوە               |
| `use`        | شێوەیەکی تر، بە قەبارەی تەواو، لەگەڵ `translate` یان `rotate` ـی ئارەزوومەندانە              |

`param rays` لە جیاتی ژمارەیەک واتای ئەوەیە بەهاکە لە پارامیتەری شێوەکە بەو ناوەوە دێت. بەشی **پارامیتەرەکان**ی پەڕەکە بە بەها بنەڕەتییەکانیانەوە ڕیزیان دەکات. `filled` بەشێک دیاری دەکات کە وەک پڕکردنەوە ڕەنگ دەکرێت نەک وەک هێڵ.

`radial` ێک بە sweep ـی 360 کۆپییەکانی بە دووریی 360 / count لە یەک دادەنێت. بە sweep ـی بچووکتر، یەکەم و دوایین کۆپی لە هەردوو سەرەکەدان. بۆ نموونە، [نیوە خۆر](https://kanilabs.github.io/deq/ckb/icons/roj-half-sun/) بە ٧ تیشک بە درێژایی 180° بە دووریی 30° لە یەک دایاندەنێت.

## پێوانەکان

| پێوانە           | واتا                                                                     |
| ---------------- | ------------------------------------------------------------------------ |
| چوارچێوەی بینراو | چوارچێوەی دەوری مەرەکەب، هێڵ و سەرە خڕەکانیشی تێدایە: x، y، پانی × بەرزی |
| چوارچێوەی سنوور  | چوارچێوەی دەوری هێڵە ناوەڕاستەکان، بێ هێڵەکە                             |
| ناوەڕاستی بینایی | ناوەڕاستی ڕووبەری ڕەنگکراو، بە کێشی ڕووبەر                               |
| هێڵ بە قەبارە    | ئەستووریی هێڵ (2) دابەش بەسەر لای گەورەتری چوارچێوەی بینراو              |
| بنەما کێشراوەکان | شێوەکە بە بەها بنەڕەتییەکان دەبێتە چەند بەشی سادە                        |

بۆ شێوەیەکی پڕکراو وەک خۆری کوردی، هەردوو چوارچێوەکە وەک یەکن.

## نموونەی کارپێکراو: خۆری کوردی

[خۆری کوردی](https://kanilabs.github.io/deq/ckb/icons/kurdish-sun/#construction) یەک بنەمای `star` ـە بە `points param rays` (بە بنەڕەت ٢١)، بۆیە دوو ڕیزی هەیە، یەکێک بۆ هەر جۆرێک:

1. ئەستێرەیەک بکێشە بە ٢١ لووتکەی دەرەوە و ٢١ لووتکەی ناوەوە، یەکەم لووتکەی دەرەوە ڕاست بەرەو سەرەوە (سووڕانەوەی −90°).
2. نیوەتیرەی دەرەوە R = 20 / (1 + cos(π/21)) = 10.056، بۆیە ئەستێرەکە ڕێک ٢٠ یەکە بەرزە. نیوەتیرەی ناوەوە R / 2 = 5.028.
3. ناوەڕاست (12, 12.056): ئەستێرەکە R لە سەرووی ناوەڕاستەکەیەوە دەڕوات بەڵام تەنها R cos(π/21) لە خوارییەوە، بۆیە ناوەڕاستەکە 0.056 دەچێتە خوارەوە تا چوارچێوەی 2 تا 22 لە ناوەڕاستدا بێت. [ڕاستکردنەوەی بینایی](optical-corrections.md) هۆکارەکەی ڕوون دەکاتەوە.
4. بۆ جۆری هێڵکراو، R − 1 و R/2 − 0.5 (9.056 و 4.528) بەکاربهێنە لەگەڵ هێڵی ٢ یەکەیی، تا لێواری دەرەوە لەگەڵ ئەستێرە پڕکراوەکە یەک بگرێتەوە.

## دووبارە کێشانەوەی شێوەیەک لە ئامرازێکی تردا

1. بەڵگەنامەیەکی ٢٤ × ٢٤ (پیکسڵ یان خاڵ) دروست بکە و تۆڕێکی ١ یەکەیی چالاک بکە. [ڕێنماییەکانی ئامرازەکان](../tools/inkscape.md) پیشان دەدەن چۆن لە هەر بەرنامەیەکدا.
2. هەر بنەمایەک لە بەهاکانییەوە بکێشە. بازنە و کەوانە ناوەڕاست و نیوەتیرەیان پێویستە؛ زۆربەی بەرنامەکان چوارچێوەیەک وەردەگرن، بۆیە x = cx − r، y = cy − r و پانی = بەرزی = 2r بەکاربهێنە.
3. هێڵەکە بکە بە 2 لەگەڵ سەر و جومگەی خڕ، و خاڵەکان وەک بازنەی پڕکراوی نیوەتیرە ١ بکێشە.
4. لەگەڵ SVG ـی بەستەری **داگرتنی SVG**ی پەڕەی ئایکۆنەکە بەراوردی بکە. زۆرجار خێراترە لەو فایلەوە دەست پێبکەیت.
